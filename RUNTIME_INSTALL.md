# QNX4 native installation

This release path builds the actual Common V2 implementation and hosted carrier, and installs `/System/Filesystems/QNX4.so` and `/System/Resources/Documentation/Filesystem-QNX4.pdf`. The existing native and production-consumer test jobs gate publication. Writable operation is restricted to the provider's own qualified on-disk profile; foreign writable interoperability and physical firmware qualification are not claimed. Native compilation uses CPU-specific optimisation; no PGO claim is made.
